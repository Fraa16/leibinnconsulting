## Workflow: Optimal Building Process

### Phase 1: Planning & Brief (15-30 minutes)
**You do:**
1. Fill out this template completely
2. Gather all assets (logos, images, copy)
3. Review and ensure nothing is missing
4. Submit in ONE message to AI

**AI does:**
1. Review brief for completeness
2. Ask clarifying questions if needed
3. Confirm understanding and approach

### Phase 2: Foundation Build (For Landing Pages: 2-4 hours | Websites: 4-8 hours)

**AI builds:**
- Complete structure with all sections
- Responsive layout
- All content populated
- Basic styling and spacing
- Core functionality (forms, navigation)

**Deliverable:** 80% complete website

### Phase 3: Review & Feedback (30-60 minutes)

**You do:**
1. Review entire site
2. Test on mobile and desktop
3. Compile ALL feedback into one organized list:

```
VISUAL CHANGES:
- [Change 1]
- [Change 2]

CONTENT CHANGES:
- [Change 1]
- [Change 2]

FUNCTIONALITY CHANGES:
- [Change 1]
- [Change 2]

BUGS/ISSUES:
- [Issue 1]
- [Issue 2]
```

**AI does:**
- Implement all changes in one batch
- Test changes
- Confirm completion

### Phase 4: Polish & Refinement (1-2 hours)

**AI does:**
- Animation fine-tuning
- Spacing perfection
- Cross-browser testing
- Performance optimization
- Responsive behavior verification

**You do:**
- Final review
- Request minor tweaks if needed

### Phase 5: Production Prep (1-2 hours)

**AI does:**
- Add SEO meta tags
- Connect forms to backend
- Set up analytics
- Optimize images
- Generate deployment instructions
- Create README with setup steps

**Deliverable:** Production-ready website

## Tips for Maximum Efficiency

### DO:
✅ Provide complete information upfront
✅ Include visual references (screenshots, URLs)
✅ Write or provide all copy before starting
✅ Batch your feedback into comprehensive lists
✅ Make decisions about colors/style early
✅ Use clear, specific language
✅ Provide examples when describing features

### DON'T:
❌ Give feedback piece by piece
❌ Change major design direction mid-build
❌ Skip sections in the brief and "figure it out later"
❌ Say "make it look good" without references
❌ Request changes before seeing the full picture
❌ Mix multiple unrelated requests in one message

### When Providing Feedback:
**Instead of:** "The spacing looks weird"
**Say:** "Increase vertical spacing between sections 2 and 3 to 80px on desktop, 40px on mobile"

**Instead of:** "I don't like the colors"
**Say:** "Change accent color from purple (#8B5CF6) to teal (#14B8A6) everywhere. Keep other colors."

**Instead of:** "Make it more modern"
**Say:** "Add subtle shadow elevation to cards, increase border radius to 16px, use a softer background color like #F9FAFB"

## Template Quick Reference

### For Landing Pages (One-Pager)
**Typical sections in order:**
1. Hero (headline + CTA)
2. Social proof (logos, testimonials)
3. Features/Benefits (3-6 items)
4. How it works (3-4 step process)
5. Testimonials (3-5 quotes with photos)
6. Pricing (if applicable)
7. FAQ (6-10 questions)
8. Final CTA (form or button)
9. Footer (links, legal)

### For Multi-Page Websites
**Standard pages:**
- Homepage (overview + key sections)
- About (story, mission, team)
- Services/Products (offerings with details)
- Portfolio/Work (case studies, examples)
- Blog (articles, resources)
- Contact (form + information)

**Each page needs:**
- Page title and meta description
- Hero section
- 2-4 content sections
- CTA (specific to page goal)
- Breadcrumb navigation (optional)
